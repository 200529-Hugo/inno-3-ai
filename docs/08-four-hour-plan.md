# Uitvoerplan — één sprint van 4 uur

## 00:00–00:15 — Scrum start
- rollen invullen;
- Sprint Goal hardop bevestigen;
- bord maken;
- DoD zichtbaar ophangen;
- één persoon start Docker, één persoon maakt Double Diamond-post-its, één persoon bereidt presentatie/evidence-map voor.

## 00:15–00:40 — Discover + Define
- post-its over gebruiker, risico, privacy, human-in-loop;
- probleemstatement en succescriteria vastleggen;
- foto's maken.

## 00:40–01:10 — Develop + technische integratie
- drie oplossingsopties schetsen;
- gekozen architectuur vastleggen;
- `docker compose up --build`;
- API Swagger openen;
- n8n workflow importeren.

## 01:10–02:00 — Kern testen
- vier testcase-JSON's via API draaien;
- daarna via n8n webhook;
- fouten direct fixen;
- GET /audit controleren;
- screenshots nemen zodra iets werkt.

## 02:00–02:25 — Niet-ICT gebruikerstests
- twee studenten zoeken;
- toestemming voor foto vragen;
- burgerbericht/reviewer-uitkomst laten interpreteren;
- feedback noteren.

## 02:25–02:45 — Feedback verwerken
- minimaal één zichtbare verbetering doorvoeren;
- tabel feedback → besluit → aanpassing invullen;
- voor/na bewijs opslaan.

## 02:45–03:15 — Presentatie bouwen
- eigen foto's toevoegen;
- Scrum-bord, BPMN, architectuur, Prompt Charter, AI-log, audit en testcases opnemen;
- taken per spreker verdelen.

## 03:15–03:35 — Oefenen met andere groep
- presentatie oefenen;
- feedback ontvangen en geven;
- concrete presentatieaanpassing doen en vastleggen.

## 03:35–03:50 — Finale technische run
- alle vier testcases opnieuw;
- screenshots/video fallback;
- workflow JSON exporteren vanuit jullie eigen n8n na import/wijzigingen.

## 03:50–04:00 — Review + Retro + uploadcheck
- Sprint Review notities;
- Retrospective;
- check alle 10 deliverables;
- bestanden klaarzetten voor Canvas.
